# wrangl

Installs the [Wrangl](https://github.com/wrangl-dev/wrangl) desktop app.

```bash
npx wrangl
```

macOS and Linux run `scripts/install.sh`, Windows runs `scripts/install.ps1`. Both download the latest release from GitHub, check it against `SHA256SUMS.txt`, and install it. Run it again to update.
