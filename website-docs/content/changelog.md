# Changelog

Releases are listed on [GitHub](https://github.com/wrangl-dev/wrangl/releases) with their files.

## Unreleased

The first release of the new, rewritten Wrangl.

- **Agents:** every agent in the ACP Registry, installed on demand, with sign-in in the chat.
- **Chat:** streaming Markdown answers, thinking, tool calls, plans and approval cards; stop a turn at any time.
- **Projects:** chats and terminals per project folder; chats keep running in the background.
- **Terminals:** tabs under the chat, toggled with Ctrl+`.
- **Chain tools:** status, token checks, balances, transactions, new pools and raw calls on Robinhood Chain, with public RPC fallbacks.
- **Settings:** your own RPC, tested before saving, and an optional CoinGecko key.
- **Wallet:** watch-only. Agents propose transactions; you sign them in your own wallet after a simulation.
- **Swaps:** KyberSwap quotes and swaps with exact-amount approvals and 0.5% default slippage.
- **Updates:** signed releases installed from the status bar.
