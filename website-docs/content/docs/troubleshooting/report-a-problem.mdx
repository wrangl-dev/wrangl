---
title: Report a problem
description: Find the Wrangl log, copy it, and report a bug on GitHub.
---

When something goes wrong, the Wrangl log usually shows why. Attach it to a bug report so the maintainers can find the cause.

## Copy the log

1. Open app settings with `Ctrl+,` (`Cmd+,` on macOS, `Alt+,` in the browser version).
2. Select **Diagnostics & Logs**.
3. Select **Copy Log Contents**.

The log is now on your clipboard. Paste it into your bug report. Read it first, and remove anything you do not want to share, such as folder names.

![The Diagnostics and Logs tab with the Copy Log Contents button](/screenshots/settings-diagnostics.png)

In the desktop app, the tab has more buttons:

- **Reveal Log Folder** opens the folder with the log file.
- **Export Log File...** saves a copy where you choose.
- **Export to Default Directory** saves `wrangl.log` in your Downloads folder.

On macOS, the **Help** menu has the same actions, for example **Reveal Log File** and **Copy Log Contents**.

In the browser version, the log is on the computer that runs the server. **Copy Log Contents** copies the server's log.

## Find the log file

The desktop app writes its log to `wrangl.log` in this folder:

| System | Log file |
| --- | --- |
| Windows | `%LOCALAPPDATA%\dev.wrangl.app\logs\wrangl.log` |
| macOS | `~/Library/Logs/dev.wrangl.app/wrangl.log` |
| Linux | `~/.local/share/dev.wrangl.app/logs/wrangl.log` |

## Find your version

A bug report needs the Wrangl version.

- In the desktop app, open **Settings** > **Updates** and read **Current Version**.
- In the browser version, open **Settings** and scroll down to **Updates**, above **Diagnostics & Logs**. **Server Version** shows the version of the server.

## Report from the app

The fastest way is the **Report a bug** button at the bottom of the left sidebar, next to **Settings**. Wrangl adds your version, system details and the end of the log for you, with private details such as folder names removed. Open **Preview** to read the exact text before you send it.

- If the [GitHub CLI](https://cli.github.com) (`gh`) is installed and signed in, **Submit report** creates the issue for you.
- If not, Wrangl copies the report to your clipboard and opens a new GitHub issue in your browser. Paste the report there and submit it.

## Report a bug on GitHub

1. Search the [open issues](https://github.com/wrangl-dev/wrangl/issues) to see if someone reported the problem already.
2. Open a [new bug report](https://github.com/wrangl-dev/wrangl/issues/new/choose) and choose **Bug Report**.
3. Fill in the form:
   - **Will you contribute a fix?** tells the maintainers if you plan to send a fix.
   - **Bug Summary** says what happened and what you expected.
   - **Steps to Reproduce** lists the exact steps that cause the problem.
   - **Environment** has your operating system, Wrangl version, Node.js version if an agent is involved, and how you installed Wrangl.
   - **Logs, Errors, or Screenshots** is where you paste the log.
4. Submit the issue.

For questions and ideas that are not bugs, use [GitHub Discussions](https://github.com/wrangl-dev/wrangl/discussions).

## No GitHub account?

Send a DM to [@usewrngl on X](https://x.com/usewrngl). Say what happened, what you expected, and your Wrangl version. Do not paste the whole log in a DM. Describe the error, and we ask for the log if we need it.
